# WordPress.org listing assets

These files are **not** part of the plugin zip. They go in the WordPress.org SVN
repo's `/assets` directory after the plugin is approved, and control how the listing
looks in the plugin directory.

Add final artwork here (from design) before the SVN `/assets` commit:

| File | Size | Purpose |
| --- | --- | --- |
| `icon-128x128.png` | 128×128 | Plugin icon (directory search results). |
| `icon-256x256.png` | 256×256 | Plugin icon (retina). |
| `banner-772x250.png` | 772×250 | Header banner on the plugin page. |
| `banner-1544x500.png` | 1544×500 | Header banner (retina). |
| `screenshot-1.png` | — | The **Settings → ChatterMate Chat** screen. Capture from a local run; must match the order in `readme.txt`'s `== Screenshots ==`. |
