# WordPress.org listing assets

These files are **not** part of the plugin zip (`.gitattributes` export-ignores this
folder; build with `bin/build-zip.sh`). They go in the WordPress.org SVN repo's
`/assets` directory after the plugin is approved.

| File | Size | Purpose |
| --- | --- | --- |
| `icon-128x128.png`, `icon-256x256.png` | 128², 256² | Plugin icon: the ChatterMate app icon. |
| `banner-772x250.png`, `banner-1544x500.png` | 772×250, 1544×500 | Header banner, rendered from HTML (store photo made with Codex). |
| `screenshot-1.png` … `screenshot-5.png` | 1440 wide | In the order of `readme.txt`'s `== Screenshots ==`. |

Reference: <https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/>
